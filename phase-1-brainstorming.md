# Phase 1 — Brainstorming & Ideation

## Problem

Many beginners want a structured workout routine but do not know how to organize exercises, recovery and weekly progression.

## Proposed solution

FitBuddy uses generative AI to turn a small set of user inputs into a structured 7-day general-wellness plan.

## Main scenarios

1. User enters profile, goal and intensity.
2. AI generates a 7-day plan.
3. AI produces a concise nutrition/recovery tip.
4. User gives feedback.
5. AI creates an updated plan.
6. Admin/coach can review stored records.

## Success criteria

- Simple interface.
- Predictable structured AI output.
- Persistent records.
- Feedback loop.
- Local reproducibility.
- Clear demonstration path.
